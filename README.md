# Домашнее задание №1 "Анкета пользователя"

## Что сделано?

Анкета с полями для ввода имени, выбора возраста, пола, подписки на рассылку и загрузки аватара. При нажатии на кнопку "Отправить" отображается краткая сводка того, что выбрал пользователь

### Функционал:

1. **Поле ввода имени**: блокирует кнопку отправки при пустом имени и выводит ошибку
    
2. **Выбор возраста**: с помощью слайдера пользователь выбирает возраст от 1 до 100 лет
    
3. **Выбор пола**: возможность выбора между мужским и женским полом
    
4. **Подписка на рассылку**: отметка через чекбокс
    
5. **Кнопка "Отправить"**: отображает сводку введенных данных
